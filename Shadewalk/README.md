# Shadewalk

Shadewalk is a native iOS app that plans **walking routes through the shade**. For the time you choose, it works out
where buildings and trees cast shadows (sun position + building heights + tree canopy) and routes you so you spend
as little time as possible in direct sun, without an unreasonable detour.

## Features

- **Map home**: full-screen map, "Where to?" search, a weather pill (temperature, feels-like, UV), my location and map layers.
- **Shade overlay**: building and tree shadows for the selected time, drawn as translucent polygons.
- **Departure-time slider**: "Now" or any time between sunrise and sunset; shade and routes update.
- **Shade-aware routing**: up to three alternatives (*Shadiest*, *Balanced*, *Fastest*). Shaded stretches are drawn in green and sunny ones in orange.
- **Route card**: time, distance and steps; shade %, slope and time in the sun; crossings, stairs and underpasses; a slope profile; cool spots along the way.
- **Follow mode**: live guidance with maneuver banners, "In shade now / Sun for the next 120 m", rerouting and arrival.
- **Cool spots**: drinking water, cool indoor places, shelters and parks.
- **Seat side**: for a bus, tram or train trip, which side of the vehicle stays out of the sun.
- **Saved places**: Home, Work, favorites and recent searches.
- **Settings**: shade preference (maximum detour), walking speed, avoid stairs, units and the default overlay.
- **Languages**: English, Russian, Ukrainian.

## Requirements

- Xcode 16 or newer (the project uses the Xcode 16 project format), iOS 17+ SDK
- iOS 17.0+ device or simulator

## Open and run

1. Open `Shadewalk/Shadewalk.xcodeproj` in Xcode.
2. Choose the **Shadewalk** scheme and an iPhone simulator.
3. Press **Run** (⌘R).

To run on a device, select the **Shadewalk** target → *Signing & Capabilities*, choose your **Team** and, if needed,
change the bundle identifier (`com.example.shadewalk`) to one you own.

SwiftUI previews use deterministic sample data (`Shadewalk/Preview/`), so they work offline.

## Regenerate the Xcode project

`Shadewalk.xcodeproj` is generated from `project.yml` with [XcodeGen](https://github.com/yonaskolb/XcodeGen).
After adding, moving or deleting files:

```sh
brew install xcodegen
cd Shadewalk
xcodegen generate
```

## Architecture

```
Shadewalk/
  project.yml              XcodeGen spec (Shadewalk.xcodeproj is generated from it)
  Shadewalk/               iOS app target: SwiftUI, MapKit, CoreLocation, SwiftData, Charts
    App/                   @main app, AppEnvironment (composition root), AppRouter, RootView
    Features/              Walk, Seat side, Saved, Settings, Onboarding screens
    DesignSystem/          Theme tokens, typography, reusable components, place search sheet
    Platform/              CoreLocation / MapKit / UserDefaults adapters, coordinate conversions
    Formatting/            Locale-aware formatters, display names, localized errors
    Persistence/           SwiftData models (saved places)
    Preview/               Fakes and sample data for SwiftUI previews (DEBUG only)
    Resources/             Asset catalog (app icon, colour tokens)
  ShadewalkTests/          App-level XCTests (iOS)
  Packages/ShadeCore/      Swift package: pure Foundation + Observation, builds and tests on Linux
    Sources/ShadeCore/     Sun position, shade engine, OSM parsing, routing, data clients
    Sources/ShadeFeatures/ @Observable view models (no SwiftUI / MapKit)
```

- **ShadeCore** holds the algorithms and data: the NOAA solar position, shadow casting from buildings and trees,
  Overpass/OSM parsing into a walk graph, shade-weighted A* routing, elevation profiles, the seat-side advisor and
  route-progress tracking.
- **ShadeFeatures** holds the `@MainActor @Observable` state machines that screens bind to, such as
  `RoutePlannerModel`, `NavigationModel` and `SearchModel`.
- The **app target** contains SwiftUI views and thin adapters that implement the package's protocols with
  CoreLocation and MapKit. `AppEnvironment` builds everything once and injects the models into the SwiftUI
  environment.

## Tests

- **Package (Linux or macOS):**

  ```sh
  cd Shadewalk/Packages/ShadeCore
  swift build --build-tests && swift test --skip-build
  ```

- **App (Xcode):** run the **Shadewalk** scheme's tests (⌘U), or from the command line:

  ```sh
  xcodebuild -project Shadewalk/Shadewalk.xcodeproj -scheme Shadewalk \
    -destination 'platform=iOS Simulator,name=iPhone 16' test CODE_SIGNING_ALLOWED=NO
  ```

CI (`.github/workflows/shadewalk.yml`) runs the package tests on Linux and macOS, builds the app for the iOS
Simulator and runs the app tests.

## Privacy

- To plan a route, Shadewalk sends the **coordinates of the area around your route** to the Overpass API (map data)
  and Open-Meteo (weather and elevation). Place searches go to Apple MapKit.
- Your location is used on device to start routes and guide you. It is requested only while you use the app; while
  you follow a walk, guidance keeps running with the screen locked (iOS shows the location indicator), and stops when
  the walk ends.
- There are no accounts, analytics or tracking. Settings, recent searches and saved places stay on your device.

## Design

Shadewalk's name, icon, visual design and copy are original. The visual language is calm, cool and legible in harsh
sunlight: deep green shade, warm orange sun, rounded numerals for metrics, and continuous-corner cards. It supports
Dynamic Type, VoiceOver and Reduce Motion, and never relies on colour alone to tell shade from sun.
